# AIPaint

AIPaint 是一个由 LLM 驱动的结构化做图工具。用户通过自然语言描述目标，AI 会在可编辑画布上创建、调整和组合图形；手动绘图能力主要用于微调 AI 生成的结果。它适合制作流程图、产品示意图、信息卡片、海报布局以及其他需要持续编辑的结构化视觉内容。

## 它和多模态直接生成图片有什么不同？

AIPaint 的重点不是让模型一次性输出一张“最终图片”，而是让 LLM 操作一张由结构化对象组成的画布。AI 负责理解需求、规划布局并执行画布操作，用户可以在生成后继续对单个对象进行编辑。

| 对比项 | AIPaint：LLM 驱动的结构化做图 | 多模态模型直接生成图片 |
| --- | --- | --- |
| 产物 | 可编辑的图形、文本、连线和图片对象 | 一张像素图片 |
| 交互方式 | 可以继续追问，按对象修改布局、文案、颜色和尺寸 | 通常重新生成整张图片 |
| 文字与排版 | 文字是独立对象，便于修改，适合流程图和信息布局 | 文字可能被直接绘制进图片，修改和准确排版较困难 |
| 精细控制 | 可查看和调整每个对象的位置、尺寸、层级和样式 | 主要依靠提示词控制整体效果 |
| 适用场景 | 流程图、产品对比图、示意图、可复用设计稿 | 插画、概念图、照片和追求视觉表现的成品图 |

简单来说，多模态直接生图更像“生成一张视觉成品”；AIPaint 更像“让 LLM 参与搭建一份可继续编辑的视觉文档”。AIPaint 也支持插入图片，但图片通常是画布中的素材或参考资料，不会取代结构化画布本身。

## 功能概览

- 通过右侧“AI 绘图”面板用自然语言生成画布，并持续对话式修改结果
- AI 可结合当前画布状态、已选对象以及图片和文本附件理解上下文
- 生成结果由矩形、文本、连线、图片等结构化对象组成，可以继续编辑和复用
- 使用矩形、椭圆、菱形、直线、箭头、画笔、文本和图片等工具对 AI 结果进行手动微调
- 添加图片、文本或代码文件作为 AI 的参考资料
- 调整画布尺寸、背景色、网格、吸附、缩放和图层顺序
- 撤销、重做、复制、删除和编辑文本
- 将场景导出为 PNG 或 JPEG，并支持 1～4 倍导出和透明背景
- 将场景保存为 JSON，之后再导入继续编辑
- 自动将当前场景保存在浏览器本地存储中

## 快速开始

### 环境要求

建议使用较新的 Node.js LTS 版本。项目使用了 Node.js 原生 `fetch`、`.env` 读取和 Abort Signal API，版本过旧可能无法启动。

### 安装并启动

在项目根目录执行：

```bash
npm install
npm start
```

启动后打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。

开发时可以使用自动重启模式：

```bash
npm run dev
```

如需修改端口或监听地址：

```bash
PORT=8080 npm start
HOST=0.0.0.0 PORT=3000 npm start
```

除非明确了解网络安全配置，否则不建议把服务直接暴露到公网。

## 配置 AI 绘图

AI 功能需要 DeepSeek API Key。配置方式有两种。

### 方式一：在网页中配置

1. 启动项目并打开页面。
2. 点击右侧“AI 绘图”标题旁的齿轮按钮。
3. 填写 API Base URL 和 API Key。
4. 点击“保存”。

默认 API Base URL 为 `https://api.deepseek.com`。API Key 在页面中只以掩码显示，服务端会将其写入项目根目录的 `.env` 文件，并尽量限制文件权限。

### 方式二：使用 `.env` 文件

在项目根目录创建 `.env`：

```dotenv
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

也可以只对本次启动临时设置：

```bash
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx npm start
```

不要把真实 API Key 提交到 Git。项目已默认忽略 `.env` 文件。Shell 中已经存在的环境变量优先级高于 `.env` 中的同名变量；如果网页保存的新 Key 没有生效，请检查并清除旧变量后重启：

```bash
unset DEEPSEEK_API_KEY
npm start
```

常用 AI 配置：

```dotenv
DEEPSEEK_MODEL=deepseek-v4-pro
DEEPSEEK_VISION_MODEL=deepseek-v4-flash-vision-exp
DEEPSEEK_BASE_URL=https://api.deepseek.com
AGENT_MAX_ROUNDS=8
AGENT_REASONING_EFFORT=medium
```

## 基本使用

### 手动画图

从左侧工具栏选择工具，然后在画布上拖拽或点击：

- `V`：选择和移动对象
- `R`：矩形
- `O`：椭圆
- `D`：菱形
- `L`：直线
- `A`：箭头
- `P`：自由画笔
- `T`：文本
- `I`：插入图片

选中对象后，可以在右侧面板调整填充色、描边、线宽、线型、透明度、位置、尺寸、旋转、字体和图层顺序。文本对象双击即可编辑。

常用操作：

- `Delete`：删除选中对象
- `⌘D`：复制对象
- `⌘Z` / `⇧⌘Z`：撤销 / 重做
- 按住空格拖拽，或使用鼠标中键：平移画布
- `⌘` 加滚轮：缩放
- `⇧` 加拖拽：保持等比

### 使用 AI 绘图

在右侧输入框中直接描述想要的画布，例如：

```text
做一张 1200×675 的三栏产品对比图，包含标题、三个产品卡片和底部购买按钮，风格简洁，使用蓝紫色配色。
```

点击“发送”后，AI 会在对话面板中返回过程和结果，并根据需要创建或修改画布。描述越具体，结果通常越容易调整；可以继续发送补充要求，例如“把标题字号加大”“将第三张卡片改成绿色”。

点击输入框左侧的 `＋` 可以添加图片或文件。图片可以作为画布素材，也可以用于版式参考；文本、Markdown、JSON、代码等文件可作为 AI 的上下文。

## 保存和导出

- 点击“存档”：将当前场景下载为 JSON 文件
- 点击“导入”：从 JSON 文件恢复场景
- 选择 PNG 或 JPEG、导出倍率后点击“服务端导出”：下载最终图片
- PNG 支持“透明底”；JPEG 不支持透明背景

浏览器会自动保存当前场景，但清理浏览器站点数据或更换浏览器后可能无法恢复，重要作品建议额外保存 JSON。

## 常见问题

### 执行 `npm install` 时 `canvas` 安装失败

`canvas` 包含原生模块。部分系统需要额外安装 Cairo、Pango 等系统依赖，并准备好编译工具。请根据当前操作系统安装 `node-canvas` 所需依赖后重新执行 `npm install`。

### 页面可以打开，但 AI 没有响应

请依次检查：

1. 是否已配置有效的 DeepSeek API Key。
2. API Base URL 是否正确。
3. 启动服务的终端是否有报错。
4. 是否存在 Shell 环境变量覆盖了 `.env` 中的配置。
5. API Key 是否有足够余额和对应模型权限。

### 页面无法访问

确认服务仍在运行，并检查终端中实际监听的 `HOST` 和 `PORT`。默认地址是 `127.0.0.1:3000`。

## 安全提示

- API Key 属于敏感凭据，不要写入提交记录、截图或公开日志。
- 默认只监听本机地址，修改为 `HOST=0.0.0.0` 后请自行配置访问控制。
- 上传的附件会参与 AI 请求，请确认其中不包含不应发送给第三方服务的敏感信息。
